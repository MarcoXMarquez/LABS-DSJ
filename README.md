# LABS - DSJ

Repositorio para los laboratorios del curso de **Desarrollo de Software y Juegos (DSJ)**.

## Estructura de Laboratorios

- **[SpaceInvader (Lab01)](./SpaceInvader%20(Lab01))**: Implementación del clásico juego Space Invaders utilizando Python y Pygame.

---

### Cómo ejecutar SpaceInvader (Lab01)

1. Ingresa a la carpeta del laboratorio:
   ```bash
   cd "SpaceInvader (Lab01)"
   ```

2. Instala las dependencias (por ejemplo, con `uv` o `pip`):
   ```bash
   pip install pygame
   ```

3. Ejecuta el juego:
   ```bash
   python main.py
   ```
